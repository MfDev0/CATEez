# CAtez

## Status

| Stage | State |
|---|---|
| Booted to main menu | completed |
| Entering the game | running at ~15 fps (RTX 4050, 5 GB VRAM, 16 GB DDR5) |

## Report

After a run, a report ZIP is created in `Downloads\VIctory-reports`. It includes
run logs, recent crash logs, settings, pipeline notes, and a system summary.
Run `MAKE_REPORT.cmd` to make a report by hand from the newest available log.
